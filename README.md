# TSL Nigeria National Resilience Twin

Interactive high-level strategy dashboard prepared as a foundation for TSL Logistics.

## Run

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm test
npm run build
npm run preview
```

## What is included

- Interactive Nigeria state map using local CC BY 4.0 geoBoundaries/GRID3 geometry.
- Six defensive homeland-security and resilience mission threads.
- Grouped infrastructure, consultancy, technology and managed-service offerings.
- TSL + Partners / TSL + Partners / TSL capability matrix.
- Interactive knowledge graph.
- Phased roadmap, governance guardrails, KPIs and cited public-source register.
- Light/dark themes, responsive navigation, keyboard access and print/PDF support.
- Full written strategy in `STRATEGY.md`.

## Data and safety boundary

This is a strategic prototype. It contains no live operational feed, classified source, personal data, precise critical-asset locations or tactical indicators. The zonal scores are illustrative planning indices, not current threat probabilities. Models advise; authorised officials remain accountable for decisions.
